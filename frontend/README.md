# ThinkInRed — frontend

Portfolio storefront for pre-owned ThinkPad/ThinkCentre gear from 2010–2020 (laptops, desktops, monitors, keyboards, mice, bags).
React + Vite + TypeScript, styled with Tailwind v4 and shadcn/ui (Nova preset), icons from lucide-react.
Not affiliated with Lenovo.
Talks to the NestJS API in `../ecommerce-main`.

## Run

```bash
cp .env.example .env   # VITE_API_URL, defaults to http://localhost:3000
npm install
npm run dev            # http://localhost:5173
```

The backend must be running, and its `CORS_ORIGIN` must include this app's URL.

## Pages

| Route          | What                                                      |
| -------------- | --------------------------------------------------------- |
| `/`            | Home: hero, categories, spotlight, featured products      |
| `/shop`        | Catalog — `?category=laptops&q=oled&sort=price-asc`       |
| `/products/:id`| Product detail with spec sheet and related products       |
| `/admin/login` | Admin sign-in (seeded: `admin@example.com` / `admin123`)  |
| `/admin`       | Product table: create / edit / delete                     |

The cart lives in the browser (localStorage); the backend has no orders API yet.

## Product images

Put image files in `public/products/` and set the product's image to `/products/<file>`
(in the admin form, or via `image` in the backend's `src/seed/catalog.ts`).
They're deployed with the site. Products without an image show their category illustration.

## Layout

- `src/lib/` — API client (`api.ts`), auth, cart, product query hooks, formatting, `categories.ts`
  (fixed category list — keep in sync with the backend's `src/products/categories.ts`)
- `src/components/product-art.tsx` — category illustrations used when a product has no `image_url`
- `src/components/` — app components; `src/components/ui/` is generated by shadcn
- `src/pages/` — route pages

Add more shadcn components with `npx shadcn@latest add <name>`.
